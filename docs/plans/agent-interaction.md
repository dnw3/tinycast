# Agent 模式交互设计

状态：v0.1 交互草案，2026-10-19，待评审。还没有 Spec 和 Plan；方向确认后补。

[打开可点击原型](agent-prototype/index.html)。原型使用虚构内容，不读写文件、不调用任何 CLI 或模型。

**一句话：选 agent 定谁来做，选文件夹定在哪做，选模式定要不要问你。**
Agent 模式不是新界面，是 Quick AI 和 AI Chat 在 agent 路由上多出来的能力。Codex、Claude Code、pi 这些
CLI 是底座，Tinycast 只做交互、授权和系统集成，不碰 agent 本身。

## 1. 原则

1. **不加新界面。** 长在面板（Quick AI）和 AI Chat 窗口上，沿用它们的骨架、`Theme` token 和键位。
2. **过程安静，决定醒目。** 工具调用压成一行可展开的汇总，字号和颜色同现有的工具行；全场只有授权卡片是醒目的。
3. **一个主操作。** 面板的主操作随状态变化：发送 → 停止 → 允许，其余全进 ⌘K。
4. **改动看得见、撤得回。** 每轮只留一行改动汇总；撤销即时生效，撤销本身也能恢复。
5. **换 agent 不换界面。** 界面只认统一事件和能力声明；某个 agent 不支持的能力，对应控件就不出现。

## 2. 借鉴了什么，怎么改成 Tinycast 的样子

参考 [AionUi](https://github.com/iOfficeAI/AionUi)、[OpenWork](https://github.com/different-ai/openwork)
的源码（2026-10-19 读取，未运行）和 Zed 的 agent 面板文档。只借交互机制，视觉一律用 Tinycast 自己的。

| 来源 | 借的机制 | Tinycast 的做法 | 不借 |
| --- | --- | --- | --- |
| OpenWork | 授权面板停靠在输入框上方，一次只显示最早的一条 | 卡片从输入框上沿升起，位置和动效同回复里的选项；多条时右上角显示“1 / 3”（两家都没有计数） | 把编辑请求显示成原始 JSON（两家都这样） |
| AionUi | 键盘一步决定；窗口外的确认气泡 | ↵ / ⌥↵ / ⎋；窗口外用 Tinycast 自己的 HUD 和菜单栏圆点 | 单字母键 Y/A/N（和输入框打字冲突） |
| OpenWork | 工具调用始终一行：运行中原地更新，结束变过去式汇总 | “使用了 1 个技能，读取了 3 处 ⌄”，展开是逐条记录 | 闪烁的 shimmer 文字（Tinycast 用 spinner） |
| AionUi / OpenWork | 计划停靠在输入框上方，显示“n/m” | 玻璃条“计划 2/3 · 起草周报”，授权卡片出现时让位，轮次结束收起 | 计划常驻 |
| AionUi / OpenWork / Zed | 改动卡片带 +/− 和 diff；OpenWork 的撤销不确认、给“恢复” | 每轮一行改动汇总，展开清单和预览；撤销原位变成“已撤销 · 恢复” | AionUi 的整套源码管理视图 |
| AionUi / OpenWork | 模式放在输入框；最宽松的模式要确认；进行中不悄悄换 | 模式控件；“自动编辑”用 Tinycast 对话框确认；进行中切换显示“询问 → 自动编辑”，下一轮生效 | YOLO / 完全访问这类模式 |
| AionUi / OpenWork | `+` 菜单里按会话勾选 Skills 和 MCP，显示 MCP 状态 | 沿用现有 `+` → 工具子菜单（`ChatToolScope`），加入 CLI 自己的 MCP 和 skills，带“未登录”等状态 | AionUi 头部的 skills 指示器（源码里写了但没挂载） |
| OpenWork | ↵ 排队，⌘↵ 中途插话 | 同样的键位，插话只在 agent 支持时提供 | 连按两次 ⎋ 停止（⎋ 在这里另有含义） |
| Claude Code CLI | “拒绝，并告诉它该怎么做” | 待确认时直接在输入框打字再 ↵，等于拒绝并把这句话交给 agent | — |
| Arc 浏览器 | 侧边栏自动隐藏，指针到左缘滑出，可以固定 | 不加新控件：现有的 ⌘B 收起后，收起状态本身变成可滑出 | 从窗口外移进左缘也触发 |
| Zed / AionUi / OpenWork | 对话按项目分组；一个工作区可以授权多个文件夹 | 项目 = 一组文件夹（各自读写或只读）+ 默认 agent 和模式；侧边栏按项目分组 | AionUi 的项目选定后不能改（这里可以改，下一轮生效） |

## 3. 三个选择

### 3.1 Agent

- 沿用现有模型选择器，分两组：**Agent**（Claude Code、Codex、pi……）和**对话模型**（Apple Intelligence、API 连接）。
- 选对话模型时，文件夹和模式控件隐藏：它们不能在本机动手。
- 中途换 agent 等于开新会话：转录里留一条分隔线“已切换到 Codex — 新会话，前文以摘要带入”。运行中换 agent 在下一轮生效。

### 3.2 位置：项目或文件夹

- 窗口：输入框行的位置控件。面板：标题栏右侧的范围胶囊“下载 · 询问”，一个菜单同时管位置和模式。
- 菜单：项目（§9）、单个文件夹、访达当前窗口、新建项目…、不使用文件夹。
- 快任务直接选一个文件夹；反复做的事建成项目。
- 不使用文件夹时，agent 在 Tinycast 的私有工作目录里运行，碰不到你的文件，skills 和 MCP 照常可用，比如写周报。

### 3.3 模式

| 模式 | 意思 | 映射（实现前需逐家实测） |
| --- | --- | --- |
| 只读 | 只看不改 | Codex 只读沙箱；Claude 只给读类工具；pi `--tools read,grep,find,ls` |
| 询问（默认） | 改文件、运行命令前先问你 | Codex 工作区可写沙箱加审批请求；Claude `--permission-mode default` 加 `can_use_tool`；pi 门禁扩展的 `confirm` |
| 自动编辑 | 文件夹内直接改，命令仍会询问 | Codex 文件改动自动、命令审批；Claude `acceptEdits`；pi 门禁扩展放行 edit/write |

“自动编辑”第一次开启用 Tinycast 对话框确认。运行中切换模式，下一轮才生效。

## 4. 转录里出现的东西

- **工作中**：转录最后一行“◌ 工作中 0:12”，计时证明它还活着。
- **工具调用**：
  - 运行中只占一行，当前步骤原地替换；
  - 结束后变成汇总，展开是逐条记录；有输出的条目还能再展开，左侧细线同思考块；
  - 图标按类型区分：读取 `doc.text`、搜索 `magnifyingglass`、命令 `terminal`、技能 `wand.and.stars`、文件夹 `folder`；
  - 失败的条目用红色三角，汇总里写“其中 1 次失败”。
- **授权的结果**：卡片原位变成一行：已允许 / 已拒绝 / 本次对话都允许。
- **改动汇总**：见 §6。
- **切换 agent 的分隔线**。

## 5. 授权卡片

### 5.1 窗口

- **位置**：从输入框上沿升起，不推开转录，转录底部让出卡片的高度。
- **结构**：
  - 主体图标；
  - 标题：动词加对象，如“运行命令”“修改 AGENTS.md”“删除 3 个文件”；
  - 副标题：来源和位置，如“lark-doc · 来自 Claude Code 的 skill”；
  - 内容：命令原文、真实 diff，或字段表；
  - 按钮。
- **三个维度互相独立**，同 Tinycast 对话框：图标说明是什么；色调只染图标，删除是红色；按钮角色决定按钮颜色。
- **按钮**：拒绝（取消角色，靠左）· 本次对话都允许 · 允许 / 创建 / 发送（主色）。
- **危险操作**：只有“拒绝 · 删除”两个按钮，没有“本次对话都允许”，也不接受 ↵，必须点按钮。
- **键位**：
  - ↵ 允许；
  - ⌥↵ 本次对话都允许；
  - ⎋ 拒绝；
  - 输入文字后 ↵：拒绝，并把这句话交给 agent。

  按钮上不印键帽，悬停时才显示。
- **多个待确认**：一次只显示一张，右上角标“1 / 3”，处理完下一张再升起。
- **“本次对话都允许”的范围**：同类操作、同一 agent、同一文件夹，只在本会话内有效。它绝不写回 CLI 的配置，沿用 MCP 的 Allow This Chat。

### 5.2 面板

- **形态**：卡片是转录末尾的一个“选中行”，用 `selection` 填充。
- **主操作**：底部胶囊变成“允许 ↵”；⌘K 里有：本次对话都允许 ⌥↵ / 拒绝 / 在 AI Chat 中继续 ⌘J。
- **⎋ 保持面板原来的意思：收起。** 卡片保留，转为后台提醒（§8）。要拒绝，走 ⌘K 或直接输入。

## 6. 改动汇总与撤销

- **汇总行**：每轮结束一行，如“改动了 13 个文件 · 重命名 12 · 新建 1 ⌄”。
- **展开后**：
  - 文件行沿用面板的行语法：文件图标、名称，尾部用灰字写 +/− 或“原名 …”；
  - 悬停出现“打开”“在访达中显示”；
  - 点击预览内容或 diff，配色用 `Syntax.inserted` / `deleted`。
- **撤销**：即时生效，原位变成“已撤销 13 处改动 · 恢复”。撤销本身可恢复，所以不弹确认。
- **前提**：Tinycast 在执行写操作前留存快照，见 §17。

## 7. 运行中

- **计划**：agent 发出计划时，输入框上方出现“计划 2/3 · 起草周报 ⌄”，展开看全部步骤。授权卡片出现时它让位，轮次结束后收起。
- **排队**：运行中按 ↵ 排队。输入框上方出现“排队中 · 文本 ✕”，本轮结束后自动发送。
- **插话**：运行中按 ⌘↵ 立即插话，只在 agent 支持时提供。转录里出现一行“已插话 · agent 会在下一步调整”。
- **停止**：发送圆盘变成停止按钮，快捷键 ⌘.。

## 8. 后台提醒

- 面板收起或窗口退到后台，任务照常继续。
- **需要确认时**，三处同时提示：
  - 可交互的 HUD 胶囊“✋ Claude Code 等待确认 · 移动 9 个文件 [查看]”，不会自动消失；
  - 菜单栏图标亮蓝点；
  - AI Chat 侧边栏里，这段对话的行上亮蓝点。

  点“查看”回到卡片。
- **完成时**：HUD 显示“✓ 完成 · 移动了 9 个文件”，`messageHUD` 2.4 秒后消失。

## 9. 项目

项目是一组文件夹加上它们的默认设置。它解决两件事：一个任务要同时用到几个文件夹，以及同一类任务要反复做。

- **组成**：
  - 名称；
  - 文件夹列表：第一个是工作目录，每个标「读写」或「只读」；
  - 默认 agent 和模式。
- **侧边栏按项目分组**：
  - 项目行显示名称和文件夹数，悬停时出现「+」，在这个项目里新建对话；
  - 项目折叠时，里面有对话在等确认，项目行就亮蓝点；
  - 不属于任何项目的对话放在「其他」里，按时间排。
- **位置控件**：输入框的位置菜单里，项目在上、单个文件夹在下，另有「新建项目…」和「不使用文件夹」。面板的范围胶囊用同一个菜单。
- **新建与编辑**：
  - 从位置菜单或侧边栏新建；也可以把一个或多个文件夹从访达拖到侧边栏，直接建成项目；
  - 侧边栏项目行右键「编辑项目…」；
  - 对话框里列出文件夹，可以切换读写或只读，并设默认 agent 和模式；
  - 用过几次的单个文件夹可以一键「存为项目」。
- **授权时机**：加入受保护的目录（桌面、文稿、下载）时，Tinycast 在添加的那一刻就触发 macOS 授权，不让它出现在任务进行到一半。
- **改动生效时间**：运行中改项目的文件夹或切换位置，和模式一样，下一轮才生效。
- **映射**（实现前逐家实测）：

  | | 工作目录 | 其他读写文件夹 | 只读文件夹 |
  | --- | --- | --- | --- |
  | Claude Code | cwd | `--add-dir` | `--add-dir`，再加拒绝写入的权限规则；询问模式下由 Tinycast 的授权回调直接拒绝 |
  | Codex | cwd | 沙箱的 `writableRoots` | 不放进 `writableRoots`（沙箱本来就允许读） |
  | pi | cwd | 门禁扩展按路径放行 | 门禁扩展拒绝写入 |

- **存储**：项目存在 AppSettings。它决定 agent 能改哪些地方，属于授予能力的配置，所以不进备份，也不进 `settings.json`，和 `mcpServers` 的处理一样。

## 10. 图片与附件

现状：AI Chat 已经能附加图片。Claude 用 stream-json 里的 base64 图片块，Codex 用 app-server 的 `image` 输入，API 路由各用各自的格式；输入框给不给这个入口，由 `AIModelCapabilities.images` 决定。Agent 模式要补的是三件事：

1. **入口更顺手。**
   - 粘贴（⌘V）、从访达拖入：和现在一样。
   - 「+」里新增「截取屏幕…」：直接调用 Tinycast 自己的截图，框选后成为附件。
   - 「+」里新增「从剪贴板历史选图…」：Tinycast 有图片剪贴板历史，终端里的 CLI 做不到这一点。
2. **附件同时给内容和路径。** 图片照旧发给模型看，同时在会话的临时目录里存一份，把路径告诉 agent。这样“把这张截图放进 docs/ 并在 README 里引用”这类任务才做得成。
3. **大文件只给路径，不给内容。** PDF、表格、长文档在 agent 模式下只交路径，由 agent 用自己的工具读；Claude Code 的读取工具本身就能读 PDF 和图片。这也绕开了现在 Claude、Codex 路由不收 PDF 的限制。

- **显示**：附件以胶囊排在输入框文字上方，带缩略图、名字和 ×；发送后，用户消息里显示缩略图（现有的 `chatImageThumb`）。
- **不支持图片的路由**：Apple Intelligence、Grok、Cursor 这几条路由上，「+」里的图片入口置灰并说明原因，沿用现有的能力判断。
- **隐私**：截图只有在你确认附加之后才会发出，Tinycast 不会自动附带屏幕内容。

## 11. 侧边栏：固定或收起

- **现状**：AI Chat 的侧边栏是 `NSSplitViewController` 的侧栏，已经能用 ⌘B 或工具栏的侧边栏按钮显示和隐藏。
- **改动**：收起之后不再是彻底不见。
  - **滑出**：指针从窗口内向左移到左缘并停留 100ms，侧边栏就以玻璃浮层滑出，盖在正文上，正文不动。
  - **收回**：指针离开浮层 0.3 秒后自动滑回；点正文或按 ⎋ 立即收回。
  - **固定**：浮层展开时按 ⌘B 或点侧边栏按钮就固定。浮层和固定状态的位置、尺寸相同，所以固定时侧边栏本身不跳，只有正文让出位置。
- **防误触**：
  - 从窗口外直接移进左缘、按住鼠标拖动（选字、调整窗口大小）时，都不触发；
  - 窗口贴着屏幕左边时，指针撞到屏幕边缘就能触发。
- **收起时不丢信息**：有对话在等确认时，侧边栏按钮上亮蓝点；浮层展开后，蓝点回到对应的那一行。
- **窄窗口**：窗口窄到放不下侧边栏时，即使是固定状态也临时按收起处理，变宽后恢复。
- **设置**：设置 › AI ›「收起的侧边栏在指针移到左缘时滑出」，默认开。不喜欢边缘触发可以关掉，只用 ⌘B。
- **实现思路（初步）**：固定状态就是现有的分栏侧栏；收起时把侧栏折叠，在窗口左缘放一条 tracking area，悬停时把同一份侧栏视图放进玻璃浮层滑出。

## 12. 设置

- **设置 › AI · 已安装的 agent**：每个 agent 一行，带开关、登录状态和版本；未安装的灰显。
- **每个 agent 自己的设置**：默认模式、常用文件夹。
- **“复用 X 自己的配置”**：
  - Skills：显示来源目录，可搜索，可逐个勾选；
  - MCP 服务器：可逐个勾选，显示状态；
  - 插件；
  - Hooks：默认关，因为它会在每次工具调用前后运行你配置的脚本。

  说明文案：“打开后，Tinycast 里的 X 会加载你在终端里用的这些配置。用它们改东西时，照样先在 Tinycast 里问你。”
- **不进备份**：这些开关授予能力，所以不进备份，也不写进 `settings.json`。
- **会话级**：输入框 `+` → 本次对话的工具。可以逐个开关 MCP、排除 skills，只影响这一段对话。
- **AI Chat 窗口**：「收起的侧边栏在指针移到左缘时滑出」，默认开（§11）。

开关和各家现有启动参数的对应关系：

| 开关 | Claude Code（现状） | Codex（现状） | pi |
| --- | --- | --- | --- |
| MCP | 去掉 `--strict-mcp-config`（`ClaudeMCPLaunch.swift`）；单个屏蔽用 `--disallowedTools mcp__名字` | 不再逐个按名字禁用；取消勾选的照旧禁用（`CodexMCPLaunch`） | `--no-mcp` |
| Skills | 去掉 `--disable-slash-commands`（`InstalledCLIProvider.swift:353`） | 待实测：本机 `~/.codex/skills` 为空，是否读 `~/.agents/skills` 未确认 | `--no-skills`；pi 会读 `~/.agents/skills` |
| 插件 | 待实测 | `features.plugins`（`CodexAppServerClient.swift:61`） | `--no-extensions` |
| Hooks | 待实测 | `features.hooks` | 无对应 |

本机的 83 个 skills 实际存在 `~/.agents/skills`，`~/.claude/skills` 是指向它的软链接，所以切换 agent 时同一套 skills 可以跟着走。

## 13. 文案

- 动词在前，用平实中文：读取了、运行了、移动了；不写 “Tool call”“Bash(…)”。
- 授权卡片的标题写“动词 + 对象”，副标题写“来源 · 位置”。
- 已完成用过去式，进行中用“正在…”。

## 14. 动效、滚动与键位

| 元素 | 动效 | Token |
| --- | --- | --- |
| 新行 | 淡入加上移 4pt | `Duration.enter` 0.18 |
| 授权卡片、计划条、排队条 | 从输入框上沿升起（上移 10pt、0.985 缩放）；收起时反向 | `enter` / `exit` |
| 汇总展开 | 高度展开，箭头旋转 | `chatFooter` / `MenuMotion.chevronAnimation` |
| 主操作文字切换 | 交叉淡入 | `hover` 0.12 |

## 15. 异常路径

| 情况 | 表现 |
| --- | --- |
| CLI 未登录 | 转录里一条提示，带“重试”；不会偷偷换到别的 agent |
| 文件夹无权访问 | 文件夹控件显示黄色三角；发送时提示去 系统设置 › 隐私与安全性 › 完全磁盘访问权限，或换一个文件夹 |
| 命令失败 | 红色三角行写明原因，可展开看输出；下一步由 agent 自己决定 |
| 中途切换 agent | 分隔线，新会话，前文以摘要带入 |
| CLI 进程退出 | “Claude Code 退出了 · 正在重启”，计时停住 |
| agent 反复做同一件事 | 卡片提示“agent 在重复同一个操作”，主按钮换成“停止” |
| 子任务发起的请求 | 卡片副标题写“来自子任务 …” |

## 16. 实现时要改的现有规则

- **[ai.md](../features/ai.md)**：
  - “Claude 没有 server 时只是文本通道”，以及 Codex 固定只读、断网沙箱：有文件夹时按模式放开。
  - 会话目前由 Tinycast 持有：Codex 用 ephemeral thread，Claude 用 `--no-session-persistence`。agent 模式下会话归 agent，删聊天时一起删。
- **[mcp.md](../features/mcp.md)**：“用户自己的 CLI server 不进入 Tinycast 线程”改为可配置，默认仍然隔离。
  - Codex 现在会拒绝非 Tinycast server 的确认请求；Claude 对非 Tinycast 工具直接回错误。
  - 打开开关后，这两处要改成走授权卡片。
- **“只有设置能收回授权”**：“本次对话都允许”沿用 Allow This Chat 的语义，永远不写回 CLI 配置。
- **新偏好**：照常加 `SettingsFileKey`；但授予能力的开关不进 `settings.json`，也不进备份。
- **AI Chat 窗口**：⌘B 和侧边栏按钮的行为不变，只是收起状态多了悬停滑出。悬停开关是普通偏好，要加 `SettingsFileKey`；项目列表决定 agent 能改哪里，不进 `settings.json`，也不进备份。
