# Agent 模式交互原型

对应 [交互设计](../agent-interaction.md)。原型是本地 HTML/CSS/JavaScript，无依赖、无外部资源，刷新即重置。

## 打开

直接用浏览器打开 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8767 --bind 127.0.0.1 --directory docs/plans
```

然后访问 `http://127.0.0.1:8767/agent-prototype/index.html`。

## 走查

1. **01 面板快任务**：↵ 发送；卡片出现后主操作变成“允许 ↵”，⌘K 看其余选项；也可以在输入框里直接打字再 ↵，等于拒绝并改口。完成后展开“移动了 9 个文件”，试一下撤销和恢复。
2. **02 窗口长任务**：发送后看计划条和工具汇总；运行中用 ↵ 排队、⌘↵ 插话；卡片升起后用 ↵ / ⌥↵ / ⎋ 处理。点模式控件切到“自动编辑”，看确认对话框；运行中切换会显示“询问 → 自动编辑”，下一轮生效。
   同一场景里：
   - 按 ⌘B 收起侧边栏，看收起的项目把“等待确认”的蓝点冒到侧边栏按钮上；
   - 再把指针从窗口内移到左缘（或点“模拟悬停左缘”），侧边栏会以浮层滑出，浮层里再按 ⌘B 就固定；
   - 用“附加截图”看输入框里的附件胶囊；
   - 用“新建项目”看多文件夹项目的对话框。
3. **03 授权**：底部切换五种卡片。“删除”不接受 ↵，只能点按钮。
4. **04 改动审阅**：展开改动，点 CSV 行预览，撤销后再恢复。
5. **05 后台提醒**：↵ 发送后马上 ⎋ 收起面板，等“等待确认”的 HUD 和菜单栏蓝点，点“查看”回到卡片。
6. **06 设置与技能**：设置页的复用开关和 skill 选择；切到“会话工具菜单”看按会话排除。
7. 顶部“异常路径”选一项再点“演示”：CLI 未登录、文件夹无权访问、命令执行失败、中途切换 agent。
8. 右上角切换浅色外观。

顶部场景导航、异常注入和底部模拟按钮是评审工具，不进入产品。所有文件、命令、模型和飞书调用都是模拟的。

## 最小静态检查

```sh
node --check docs/plans/agent-prototype/app.js
```
