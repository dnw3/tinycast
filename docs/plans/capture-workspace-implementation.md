## 本次可操作的路径

1. Capture Screenshot → 拖出区域 → 直接画箭头、文字、遮盖等标注 → Return / Command-C 复制结束。
2. 同一工作区选择区域、窗口、屏幕；窗口采用独立窗口图像。选区可移动、八方向缩放，几何变化可撤销。
3. Screenshot / Scrolling Screenshot 切换保留原截图与标注。长图明确点击 Start Scrolling，解除冻结后采集原窗口。
4. 长图结果与原截图分别保留文档、来源、撤销记录；结果窗口提供切换入口。空会话结束恢复原截图，关闭检查两份未保存结果。
5. Copy、Save、Pin、Extract Text、Translate、Expand Editor 直接出现在图标栏。相关颜色/粗细按当前工具出现。
6. Save 暂时隐藏桌面遮罩，保存或取消后恢复；Expand Editor 继续使用同一文档和撤销状态。

图标为 16 pt，点击区域为 30 pt，并随 InterfaceMetrics 缩放。小选区和屏幕边缘使用统一布局计算避免两个操作条重叠。
窗口重选时隐藏旧图的标注/输出动作，Command-C/S 与 Return 不会误处理旧图；Escape 可返回已有选区。
区域切换到窗口可撤销恢复旧图；进入长图时若来源是窗口/整屏，要求圈定窗口内实际滚动区域。

## 实现边界

- `CaptureRequest` 明确范围、截图/长图方式与初始内容动作。既有快捷命令构造同一请求，换屏继续保留意图。
- `CaptureCoordinator` 仍由 AppCore 唯一持有；`CaptureWorkspaceState` 只保存当前冻结工作区。
- 桌面与独立编辑器共用 `CaptureCanvas`、`CaptureEditorState`、标注工具、渲染器和输出链路。
- `CaptureUndoHistory` 保留几何、片段引用与编辑快照，不持有解码像素。异步窗口采集仍检查当前 workspace 和取消状态。
- `CaptureSourceArchive` 发布草稿时物理裁出选区，不把冻结的整屏或旧窗口图像一并留入历史。
- 没有迁入 Macshot 源码、依赖或全局单例；本轮借鉴交互，复用 Tinycast 已有原生实现。

### WebP 关闭回落的最终修复（2026-09-29）
