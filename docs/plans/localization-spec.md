# 应用本地化

## 产品契约

- 第一批支持 English 与简体中文，默认跟随 macOS 的应用语言选择；品牌、快捷键、文件路径、用户内容和第三方扩展文案不改写。
- 使用 Apple String Catalog，英文原文作为键。SwiftUI 字面量直接本地化；需要 `String` 的原生菜单、提示和动作在构造处使用 `String(localized:)`。
- 模型保留纯数据及稳定标识。枚举显示名在展示边界解析，设置搜索与滚动定位继续使用稳定英文键，同时匹配中文显示名。
- 截图、长截图、翻译、设置、启动器及公共菜单使用同一套术语。中文文案简洁，不能以图标放大、工具栏变宽或新增常驻说明为代价。
- 数字和插值保留格式占位符，不拼接翻译句子。权限用途描述提供中文。
- 新增文案必须进入资源并提供中英文；新增语言沿用现有资源，不另建翻译状态、网络服务或全局单例。

## 验收

资源可编译；占位符一致；中文及英文查找均正常；用户文本不发生翻译；设置搜索能用中文并定位正确；语言选择不改变持久化标识。Debug 无新增警告，全量 harness 和 lint 通过。原生复验菜单、截图及设置中英文布局。
