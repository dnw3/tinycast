# Capture 功能与交互收敛 Spec

日期：2026-10-10。适用当前 fork；补充 capture-spec.md，不替换其资源、隐私和生命周期约束。

## 目标与依据

把「功能已有」与「日常好用」分别验收。参考 MacShot 官方功能说明和公开工具栏实现：
https://macshot.io/ 、https://github.com/sw33tlie/macshot 。这不是同机性能或稳定性结论。

普通截图的主路径是：热键 → 选区 → 可选标注 → 复制或保存 → 返回原应用。
深度编辑仍可展开；不删除已有能力，不改变复制设置，不丢失未发布内容。

## 本轮交付

### 交互

- 选区确定后，区域/窗口/全屏、截图/长截图/录屏收进 Capture 菜单；选区前保持直接选择。
- 默认工具为选择、箭头、矩形、文字、遮盖；其余进入按用途分组的 More Tools 菜单。
- 保留已有工具栏自定义；不重置用户已保存的布局。More Tools 不再原地增加一排工具。
- 普通截图的颜色、粗细、字体等通过紧凑 Style 菜单修改；精确旋转和自定义颜色留在编辑器。
- 更多工具的图片调整和美化先展开编辑器，避免截图现场出现完整检查器。
- 输出维持直接复制、保存、贴图、OCR、翻译；保存菜单明确提供 Save As。
- 普通按钮与菜单按钮使用相同方形单元，三档界面尺寸分别为 30/33/36pt；图标在缩放后的 16pt 区域内等比居中，隐藏原生菜单箭头，避免按钮宽度及中心线不一致。
- Esc 保持撤销临时状态的既有语义；关闭按钮明确标为 Close Capture（⌘W），直接走保留检查。

### 快速保存

- 保存主按钮打开 Save As 选择位置；⌘S/Quick Save 直接保存最终合成图片，⇧⌘S 另存为。
- 默认目录为 ~/Pictures/Tinycast；设置可选其他目录，settings.json 同步 capture.quickSaveFolder。
- 默认目录按需创建；用户指定目录若失效须报告错误，不能悄悄改存到别处。
- 文件名含时间与唯一标识；发布不得覆盖已有文件，失败或取消清理中间文件。
- 复用现有格式、尺寸、色彩空间、WebP helper 与历史记录；遮挡后图片才可输出。
- 保存成功后仅关闭同一文档和 revision 的普通截图工作区；编辑器保留。失败保留编辑状态。
- Save As 的目录、格式与覆盖确认维持现有语义，不隐式更改快速保存目录。
- 快速保存目录为设备本地路径，不进入备份；Debug/Release 仍分别持久化。

## 功能差距路线

| 项目 | 当前能力 | 下一步与优先级 |
| --- | --- | --- |
| 快速保存 | 每次打开导出面板 | P0，本轮实现 |
| 常用操作层级 | 模式、标注和属性并列，多处展开 | P0，本轮实现 |
| 标注样式 | 基础箭头、字体、颜色、填充 | P1，后续独立实现箭头样式与富文本，先定义文件格式和渲染一致性 |
| 长截图 | 横/纵、手动/自动 | P1，优先真实页面成功率与接缝验收，不重复造引擎 |
| 美化 | 渐变/网格/窗框/阴影 | P2，补预设前先做渲染视觉验收 |
| 录屏 | MP4、GIF、音频、摄像头、剪辑，最高 60fps | P2，120fps 先测平台能力与现有内存预算，不直接放宽限制 |
| 上传 | S3/imgbb/Drive 已实现 | P1，真实账号授权、上传、下载比对待验收，不声称已完成 |

## 验收

自动检查：完整 harness、Debug 编译无新增警告、lint 无新增问题、Model 纯度检查。
快速保存必须用私有临时目录验证独立解码、已有文件保护、取消清理、目录错误及重复保存。

人工验收：原生应用中的区域/窗口/全屏；小选区及屏幕边缘；选择/箭头/文字/遮盖；
More/Style 菜单不使工具栏换行；自定义布局保留；快捷键与按钮结果相同；保存后焦点恢复；
Save As 取消可继续编辑；复制遵守 closeAfterCopy；长截图和录屏入口仍可到达。
按 docs/plans/capture-acceptance.md 的既有资源 gate 验收，不将编译成功当成原生实测。

长截图专项矩阵：ChatGPT/浏览器长页面、静态文档、固定头部、动态加载、横向滚动；
每种记录选区、轴、手动/自动、成功/失败原因、接缝及最终尺寸，不包含私人内容。
上传专项：各服务分别验证授权取消、网络失败、成功上传后的下载文件一致性。
