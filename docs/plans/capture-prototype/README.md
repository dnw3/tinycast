# Capture 一期交互原型

对应 [Spec](../capture-spec.md)、[Plan](../capture-plan.md)、[交互设计](../capture-interaction.md)。
原型是本地 HTML/CSS/JavaScript，无依赖、无外部资源，刷新重置模拟状态。

## 打开

可以直接用浏览器打开 `index.html`，或在 Tinycast 仓库根目录运行：

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory docs/plans
```

然后访问 `http://127.0.0.1:8766/capture-prototype/index.html`。

## 走查

1. 选择“选区”：普通截图默认“复制”，Return / Command-C 完成；另走“编辑”，不添加标注便关闭，不弹确认。
2. 默认打开长截图。用选区内滚轮或底部“模拟滚动一段”增加内容；暂停、继续、完成进入编辑器。
3. 点击“自动滚动”，观察尺寸增长；异常路径选择“拼接失败”，点击“演示”，保留已有内容进入编辑器。
4. 从入口搜索“长截图”，在选区界面选择横向，检查捕获、编辑器和历史中的尺寸保持一致。
5. 编辑器选箭头/矩形/画笔后拖动画布，或“添加示例标注”；撤销/重做，再检查保存失败和重试。
6. 取字后在同一面板翻译，校正原文仍保留；“OCR 文本超过翻译上限”应提示选择部分文字，不自动截断。
7. 权限异常 → 模拟前往系统设置 → 显式重试；既有图片编辑不要求捕获权限。
8. 贴图透明度、历史回开、设置的复制后关闭开关，以及 Light/Dark 切换。

页面顶部的场景导航、异常注入和底部模拟按钮属于评审工具，不进入产品。
所有图片、复制、保存、权限、OCR 和翻译结果均为模拟，不读取桌面、剪贴板或用户文件。
像素级裁剪、完整 Undo、IME、多窗口及其他原生差距见交互设计 §12。

## 最小静态检查

```sh
node --check docs/plans/capture-prototype/app.js
```

浏览器检查结果记录在 [Plan 的本轮交付](../capture-plan.md#13-决策记录与本轮交付)。
