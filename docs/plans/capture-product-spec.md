# Capture 完整体验 Spec

日期：2026-10-10。状态：实施中。适用 `dnw/capture-workspace`。
本 Spec 汇总工具组织、标注能力与质量验收；补充而不替换 [Capture 基础约束](capture-spec.md)
和 [效率 Spec](capture-efficiency-spec.md)。功能事实以 [Capture 文档](../features/capture.md) 为准。

## 目标与对照依据

普通截图、长截图、标注、识别和输出形成连续工作流；默认简洁，完整能力可发现，用户可决定常驻工具。
“优于 MacShot”以步骤、可发现性、渲染一致性与实测成功率衡量，不以按钮数量或编译成功代替。
参考 MacShot [公开功能清单](https://github.com/sw33tLie/macshot#all-features) 与
[工具栏源码](https://github.com/sw33tLie/macshot/blob/main/macshot/UI/Toolbar/ToolbarDefinitions.swift)。
仅参考交互与功能，不复制其 GPL 代码或素材；不同机器的宣传数字不构成性能比较。

## 基线与差距

| 领域 | 已实现 | 要补充或验收 |

| 输出 | 快速保存、Save As、PNG/JPEG/HEIC/AVIF/WebP、历史、贴图、上传 | 三类真实服务授权与下载比对；同内容输出一致性 |

## S1：完整工具目录与常驻控制（P0）

- 底部负责标注，右侧负责捕获/识别/输出。选择、撤销/重做、关闭/取消与布局导航保持稳定。
- `…` 始终为省略号，标签为 All Tools，不因隐藏工具被选中而变成另一个图标。
- All Tools 按用途分组为子菜单，列出可用工具，包括已经常驻的工具；点击执行，不改变常驻偏好。
- Customize Toolbar 打开独立自定义面板，勾选表示常驻；立即更新，关闭面板不丢设置，Reset 恢复默认。
- 右侧的 Copy、Save As、Scroll Capture、Record Screen、Pin、Extract Text、Translate、Share
  以及 Upload 同样可勾选；隐藏后仍可从目录执行，已有快捷键不依赖按钮可见性。
- 新用户默认常驻选择/箭头/矩形/文字/遮盖，以及复制/保存/滚动/贴图/OCR/翻译。
- 既有标注选择完整保留；首次升级加入默认操作入口，后续不得把用户隐藏的入口重新启用。
- 滚动与录屏仅在桌面选区上下文可用；导入图、编辑器和多屏合成不假装具有活的捕获区域。
- 普通截图选区 → Scroll Capture 直接手动纵向采样；菜单选择方向或调整选区，保留标注与返回语义，不自动滚动。

S1 验收：私有偏好域中的旧配置升级/重启/隐藏操作/Reset；原生三档按钮几何；
普通截图复用选区、隐藏后可执行、编辑器无无效捕获按钮，忙碌时不能启动第二操作。

## S2：排序与空间管理（P0）

视觉原则：美观、简洁、易用优先；按钮等大不等于符号强制拉满。符号保持系统比例，
箭头、展开和关闭适当缩小视觉尺寸，点击面积不缩小；不通过堆叠按钮宣称功能增强。

- 两条工具栏各自调整顺序，顺序稳定持久化；跨组放置不混淆职责。
- 自定义提供实时布局预览，不要求用户反复截图试布局；可恢复默认。
- 超出当前显示器可用空间的常驻项进入溢出，不增加多排标注栏，不改变持久顺序。
- 小选区、四边四角、三档界面尺寸、明暗桌面验收；所有目录/属性仍可达，关闭按钮始终可达。
- 目录支持名称搜索，中文/英文名称及快捷键可识别；键盘和 VoiceOver 可使用。

## S2.1：无感截图接管与选区基础质量（P0，先于标注扩展）

目标：点击截图后，静态桌面的位置、比例、清晰度和颜色保持稳定，只出现必要的光标与操作提示。
动态内容冻结必然停止，不承诺动画继续播放。依据用户两段视频，以及本地 MacShot `39bcead`
[接管分析](capture-startup-analysis.md)；借鉴稳定呈现，不照搬其默认全屏压暗或旧 API fallback。

### 捕获与显示

- 原分辨率 CGImage 直接进入固定底图层，与选区、遮罩、像素提示和编辑画布分层。
  关闭窗口/图层隐式动画，显示前固定 frame、backingScale 和布局；不能先模糊后清晰。
- 待选阶段保持原亮度，开始拖选后才在选区外压暗。非目标屏不能无故变暗。
- 显示用截图保留窗口阴影，使用 local display intent 和所在屏幕色彩空间；源瓦片仍归一化为 sRGB，
  取色、OCR、遮挡与导出保持既有约束。验证色彩标签、Retina 和不同缩放，不能靠强制缩放掩盖尺寸错误。
- 按显示器复用空窗口；关闭时清掉内容视图、第一响应者、底图和会话引用；显示器移除时淘汰窗口。
  工具栏宿主仍按会话构建；如果首帧耗时仍异常，再按测量结果优化，不保留旧会话以伪造预热。
- 保留 filter 排除 Tinycast 自身窗口的语义，暂不直接迁入 MacShot rect API；窗口信息也用于吸附与选窗。
  不引入旧系统捕获 API，不在启动时截图、申请权限或用近透明置顶窗口“预热”。

### 源准备与生命周期

- 底图显示不等待源瓦片持久化。创建真实的 source 租约和元数据后展示，后台任务写入瓦片。
- 源准备由 CaptureCoordinator 持有且随会话取消；允许立即拖选，只保留最后一次有效选区。
  准备完成前不创建可导出的 editor，不启用依赖源文件的编辑、识别和输出；显示简短准备提示。
- 准备成功仅对仍相同的 workspace 应用最后选区；切换 scope 丢弃旧待选项。
  关闭、换屏、睡眠/显示器变化取消源任务；旧任务不能打开新编辑器、清空新任务或覆盖新会话。
- 源文件由后台工作的强引用租约保活，不能清理尚在写入的目录；失败关闭当前浮层并报告，不能发布半份源。
- 单屏 64MP，多屏合计 64MP；不扩大画布瓦片预算。明确记录显示准备、实际可交互、源就绪三个阶段，
  不能把函数返回或后台任务完成时间冒充屏幕首帧时间。

### 光标、工具栏与像素辅助

- 进入选区立即设置十字；按钮/菜单/选区外为箭头，文字为 I-beam，边框为对应方向缩放。
  重新选择、暂停/恢复、关闭均遵守状态，不允许十字泄漏。系统指针和导出光标偏好分别验收。
- 选区前 Close/Cancel 并入底部同一表面；选区后的输出侧栏宽度为一个按钮加共享内边距。
- 选区前和拖选中提供原始像素放大、sRGB HEX 与像素坐标；四角避让，工具栏上/完成选区后隐藏。
  不抢焦点，不自动复制，不增加独立取色模式或 RGB/HEX 菜单。

### 验收

- 原生底图层 1×/2× 单像素条纹测试；源未就绪时连续改选、窗口/跨屏选择、切 scope、取消及迟到完成测试。
- 同机首次和连续启动、明暗桌面、阴影、外接屏及不同布局，测时间和峰值内存，关闭后检查释放。
- 物理 Control+1 与连续视频检查位置、缩放、重影、亮度、清晰度及光标。静态截图和代码检查不能证明无抖动。
- 新视频回归未通过前，不把 S2.1 标成验收完成；实测记录写入 Plan，不以 MacShot 源码推测代替结果。

## S3：高频标注（P1）

### 箭头与形状

单向/双向/粗箭头/开放箭头与反向；曲线控制点可编辑。图形提供描边/填充/描边加填充，
矩形圆角有界。样式保存在文档，预览、导出、撤销、历史一致；旧文档默认保持原样。

### 文字

粗体、斜体、下划线、删除线，段落左/中/右对齐，文字背景与描边；文本框可调整。
先定义可持久化样式片段和 UTF-16 边界，再接原生编辑器；覆盖中文输入法、emoji、混合字体、
多行、局部选择样式和重新编辑。不可只美化编辑视图而导出丢样式。

### 遮挡

统一 Censor 入口，含 Solid/Pixelate/Blur/Erase；保留旧文档各工具编码与快捷键语义。
建议遮盖仍需审阅；Text Only 使用 OCR 的文字框，不把检测宣称为全部隐私已清除。
模糊仅为视觉处理；遮盖后的独立解码检查、取色、OCR、翻译与上传不得暴露被遮挡原像素。

Text Only 对当前合成图运行 OCR，沿用 Include/Previous/Next/Apply 审阅后生成实色遮盖；
识别不到或结果截断明确提示。旧工具栏中 Pixelate/Blur/Erase 合为首个位置的一项 Censor，
任一原项目常驻则保持 Censor 常驻；B/M/F/E 及旧文档编码保持。
实色遮盖与擦除在卷积、锐化、像素化采样前应用，禁止隐藏源像素通过邻域处理影响输出。

## S4：滚动截图与连续工作流（P1）

矩阵：ChatGPT、浏览器、静态文档 × 手动/自动 × 纵向/横向；覆盖固定头部、动态加载、重复行、
屏幕边缘和遮挡。每例记录版本、选区/轴、输入方式、耗时、输出尺寸、接缝、失败原因。
失败/取消保留已有结果；原截图与滚动结果可返回，标注不偷偷烘焙进新帧。
记录峰值与关闭后恢复；沿用现有资源 gate，不放宽预算来掩盖失败。
上传用用户已有配置，验证授权取消/失败/成功下载一致性；没有凭证保持未验收，不创建外部账号。

### S4.1：长截图界面连续性（用户反馈补充，2026-10-11）

依据已安装版原生操作与本地 MacShot 39bcead 源码；不是新版 MacShot 同机实测结论。
MacShot 沿用选区，独立 nonactivating HUD 仅显示状态、自动滚动及停止，单行约 36 点高。
独立窗口有点击穿透和目标应用焦点的用途，不要求合并底层窗口；用户应只感知同一选区和控制条。

- 已选区点长截图后直接进入手动纵向采样，不再强制点击第二次 Start Scrolling。
  专用长截图入口仍先选区；进入前验证目标、选区及权限，失败留在原截图并明确提示。
- 方向可在进入前的长截图菜单选择；采样开始后切轴需明确重选，不混合横纵条带。
- 原选区边界几何保持一致，冻结底图切回实时内容；隐藏编辑手柄，不叠加第二个选区框。
- 控制条沿用截图工具栏的字形、按钮高度、圆角及间距，状态变化保持固定锚点与主要按钮位置。
  常态仅单行：累计尺寸、自动滚动开关、暂停/继续、完成、完成并另存为、更多；
  按 S4.2 使用等大按钮和明确悬停标签，保存与完成共用现有字形和尺寸。
- 取消、重新选择、详细尺寸及累计预览放进更多或按需展开；Escape 保留取消语义。
  预览不常驻占用第二行；错误才展开可操作提示，按钮不被长提示挤出。
- 控制必须位于采样区外并考虑 visibleFrame、刘海及缩放；空间不足明确处理，不能盖住正文偷偷采样。
- 点击控制不使目标应用失去可滚动状态；暂停恢复、自动切换、重新打开应用均验证真实前台目标。
- 无新增内容取消回到原截图原有展示模式；有新增内容保留 Back / Discard / Keep Result 选择。
  完成进入结果编辑器，取消不得意外打开另一种编辑窗口。原标注及撤销状态保持。
- 采集时保留源应用键盘焦点，不全局劫持源应用的保存快捷键。控制条提供
  Finish and Save As，一次点击停止采集、进入结果并打开另存为；取消保存保留可编辑结果。
  首个有效帧尚未就绪时禁用该保存动作，避免空会话退回原图却没有保存反馈。
  控制条获得键盘焦点时支持Shift-Command-S，源应用获得焦点时不宣称该快捷键由Tinycast处理。

验收记录选区前后几何、点击步数、三个界面尺寸档、正常/暂停/错误/完成/取消的界面证据；
单行控制条不得以删除功能、吞错误、放松遮挡检测或全局拦截鼠标移动换取简洁。

## S5：精细工具与样式（P2）

编号支持 1/I/A/a、起始值与引线；画笔平滑，高亮可选文字行吸附；各自覆盖撤销和渲染。
编号限定 1–3999，字母超过 Z/z 后使用 AA/aa；Next 可设起始/继续值，达到上限明确要求重新选择。
引线从圆形编号拖至目标点，在 Select 下端点可单独拖动，改变引线不移动编号的旋转中心。
新画笔默认 Smooth，可关闭或修改已选笔迹；旧文档缺失该字段保持原折线。
高亮默认 Freehand；Text Lines 从当前合成图识别文字，水平/矩形拖动只高亮所选横向区间。
跨行生成独立可编辑高亮，一次拖动一次撤销；拖动预览与提交一致。识别为空保留自由画笔，
部分识别明确提示；连续高亮复用行框，几何和非高亮内容变化清空缓存并回到 Freehand。
异步识别核对取消、编辑器/文档身份和 revision，不将旧行框应用到新内容。
美化提供 Gradient/Paper/Grid/Window 四套预设、自定义样式保存/覆盖/删除；布局参数与颜色同文档持久化。
自定义预设最多 20 个，名称 1–40 字符且不含控制/换行字符，名称忽略大小写判重；
由既有 CaptureSettingsStore 持有，settings.json 与配置备份携带同一列表，非法导入整体拒绝。
源图不变，预览、PNG、其他格式、历史与识别坐标保持一致；参数超限明确报告。

## S6：录屏与性能（P3）

先记录设备、SDK、系统、可用帧率、实际编码帧时间与资源，再决定 120fps 暴露条件。
覆盖持续录制、音轨同步、摄像头/按键组合、暂停恢复、取消和关闭回收。未达标不开放选项。

## 通用交付标准

每阶段完整 harness、Debug 无新增警告、lint 无新增问题、Model 纯度、文档更新。
涉及模型新增字段必须验证旧文档解码默认值、撤销、历史重开和独立解码最终像素。
涉及 UI 必须保留匿名原生渲染证据；组件离屏预览与完整真实交互分别记录。
只有同机同场景实测才能作与 MacShot 的效率/稳定性比较，未测项明确标注。

## 飞书视频对照补充（2026-10-11）

依据用户提供的本机视频 `20261011-010945.mp4`（约 14.27 秒），仅参考可见交互，不复制代码或素材。
0–4 秒可见随指针/拖选端点的像素放大与颜色信息；约 5 秒完成选区后放大镜消失、出现单排工具栏。
取消叉号与完成对勾有明确区分。视频开头已在截图状态，无法证明热键到首帧的延迟或稳定性。

本项目据此要求：拖选期间保留像素辅助、松手立即收起；工具栏禁止抢占拖选阶段；
完成与退出明确区分。继续保留可自定义常驻项与完整目录，默认工具栏的密度不能因“功能更多”增加。

### 对照取舍

借鉴清晰稳定、状态准确和拖选定位，不照搬飞书整条长工具栏、全功能默认常驻或按钮配色。
保持 Tinycast 的简洁默认项、自定义目录和现有输出语义；轻量像素辅助不增加独立取色模式，
不自动复制色值，也不追加与截图定位无关的参数。完成/退出的可发现性按实际工作流验收。

## S4.2：截图与长截图连续体验及保存可发现性（P0，2026-10-11）

根据用户实际反馈补充，优先于新增功能：

- 普通区域截图点长截图后复用选区，保持当前画面直到采样准备完成，不先跳到第二个准备工具栏。
  原始标注与撤销栈仍可返回；需要重新选取活区域的窗口截图明确进入选区调整。
- 长截图沿用普通截图的毛玻璃、圆角、等大按钮和符号尺度。仅展示累计尺寸和必要操作，
  完成使用同尺寸勾选按钮；预览与详细信息按需展开，错误和暂停状态仍明确可见。

  清空搜索恢复排序。菜单与 VoiceOver 提供上下移动操作，不常驻大箭头。
- 普通截图与长截图结果编辑器的保存主按钮统一为 Save As，打开系统保存面板选择目的地。
  ⌘S 保留快速保存，⇧⌘S 另存为；菜单使用实际快捷键绑定，文字编辑时保存快捷键仍有效。
