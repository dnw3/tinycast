# 原生翻译一期 Spec

状态：一期代码已实现，Mini、失焦/置顶、展开收起和 AI 中英翻译已实测；跨应用回填仍待授权后验收。
实现说明见 [功能文档](../features/translation.md)，验证记录见 [Plan](translation-plan.md)。

## 目标与范围

同一个 Translate 命令和快捷键覆盖选词翻译与手输翻译。默认中英自动互译，允许纠正
源语言、固定目标语言、选择 Apple 或现有 AI 连接，并在明确操作后复制或回填。

一期包含独立翻译窗口、独立设置、语言判断、流式 AI、取消、失败恢复、目标核对。
OCR、鼠标划词气泡、TTS、历史记录和多个引擎同时查询不在一期范围内。

## 交互

```text
Translate             [Apple / AI ▾] [置顶] [展开] [关闭]
[自动识别：英语 ▾]  →  [自动：简体中文 ▾]
原文
┌─────────────────────────────────────────────────┐
│ 可编辑的多行原文                                 │
└─────────────────────────────────────────────────┘
停止输入后自动翻译 · Shift+回车换行
译文 / 正在翻译                         [复制图标] [⋯]
│ 流式文字，支持选择和复制                         │
```

- 打开前记住原应用、可读取的原控件与选区。有非空选区即自动翻译。
- 无选区、无权限或无法读取时仍打开输入框；不擅自使用旧剪贴板内容。
- 取词不模拟 Command+C：部分编辑器无选区时会复制整行，无法据此证明用户选中了文字。
- 手输不要求辅助功能权限。取词与回填需要权限；授权只由明确的设置操作请求。
- 手输、粘贴停顿 800 ms 后自动识别并翻译，连续编辑重置防抖；清空输入和关闭窗口取消待触发请求。
- 回车立即提交并取消防抖，避免重复请求；Shift+回车换行。输入法候选期间不发请求，确认后重新计时。
- 删除底部 Translate / Replace / Copy 按钮行。复制图标在译文右上角，点击后显示对勾，长结果滚动时仍可用。
- 译文旁的 `⋯` 菜单提供重新翻译和插入/替换原选区；无可靠目标时禁用回填，不删除回填能力。
- 引擎与语言菜单均显示原生下拉箭头，Apple / AI 当前选择带勾选标记。
- Command+C 保持原生选中文本复制；Command+Shift+C 复制完整译文。
- Command+Return 请求回填；Escape 取消请求并关闭；输入法候选期间 Escape 交给编辑器。
- 非激活 NSPanel 获取 key focus，避免切换原应用；窗口可拖动并限制在当前屏幕内。
- 默认在鼠标所在屏幕的可用区域右上角打开约 420 pt 宽的 Mini 窗口；空白状态直接聚焦原文。
- Mini 的译文区域按内容增高，超过 220 pt 后滚动；空白状态不占用译文区。
- 窗口可拖动；内容变化与展开收起保持当前右上角并避开屏幕边缘，新查询回到默认右上角。
- 展开为约 640 × 540 pt 的编辑窗口；收起、展开和置顶不重启翻译，不清除本次输入和结果。
- 未置顶时失焦自动关闭，取消任务并清除本次目标；置顶后可跨应用对照。展开不会自动置顶。
- 语言和引擎菜单属于当前交互；回填主动激活原应用时暂缓失焦关闭，投递成功后关闭，失败保留结果。
- 关闭与新查询恢复默认 Mini、未置顶状态。尺寸随 Tinycast 的 Interface Size 缩放。
- 再次在外部应用触发开始新查询；在翻译窗口内部触发只聚焦原文，不读取自身。
- 修改原文、源语言、目标语言或引擎使旧结果失效，旧请求不得更新当前状态。
- 译文完成前禁用回填；错误和取消后的部分译文不能作为完成结果回填。

## 语言与引擎

- 第一语言默认 `zh-Hans`，第二语言默认 `en`，可在设置中修改。
- 自动目标：源语言与第一语言同族时使用第二语言，其他源语言使用第一语言。
- 简繁中文在方向选择时视为同族，但保留实际语言标识供引擎使用。
- 手动源语言覆盖检测；手动目标覆盖自动方向。每次新打开恢复自动源与自动目标。
- 识别综合 NaturalLanguage 候选、偏好语言、短缩写和混合文本；不把所有汉字判为中文。
- 空白不提交；纯数字与符号无需翻译；未知语言提示手选源语言。
- Apple 是初始引擎；AI 模型由翻译设置独立指定，复用 AIProviderFactory 与凭据。
- 不继承 AI Chat 的对话、系统提示词、联网搜索或工具。失败不自动更换服务。
- Apple 使用已安装语言；未安装语言对提供设置入口，不能把缺失语言包报告为成功。
- AI 仅返回译文，保留数字、代码、链接、段落；输出预算覆盖允许的输入。
- 服务报告长度截断时必须显示未完成，禁止回填。

## 回填

支持两种意图：替换启动时的原选区，或插入启动时的空选区。
可验证目标记录应用、控件、原文字内容和选区；回填前重新核对。
只读或不能可靠核对目标时只提供复制，不宣称可安全替换。
目标变化时保留结果并提示重新选择位置，不能写入当前任意焦点。
复用 TextInjector 的投递和临时剪贴板机制，所有生成完成后一次性投递。

## 架构

`Features/Translation/{Model,Service,UI,Settings}` 为独立功能。
AppCore 持有设置和 coordinator；视图经环境访问 coordinator；没有新的单例或 actor。
Model 只含 Foundation / CoreGraphics 纯值运算；平台句柄留在 Service。继续使用 `command:translate`，其类别
按 CommandID 声明，设置归属由 SettingsTab.ownedCommands 声明。
原 Quick Actions 删除翻译专用逻辑，其他文本操作保持原行为。
网络复用独立 ephemeral AI session；翻译配置不通过备份隐式启用外部文本投递。

## 验收

1. 无选区手输停顿后自动翻译；中文输入法候选期间不翻译，确认后重新防抖，不回填。
2. 中英双向、简繁、混合文本、短缩写、未知语言与手动覆盖有固定样本。
3. 新查询、编辑、切换引擎与关闭均取消旧工作，过期结果不能覆盖新状态。
4. Apple 缺语言包、AI 未配置、失败、空结果、长度截断有明确恢复路径。
5. 原控件或选区变化时拒绝回填，完整保留译文；原目标有效时正确替换或插入。
6. 完成 focused harness、完整 run-tests、lint、Model 纯度检查与无新增警告的 Debug build。
7. 原生窗口验证 Mini、展开收起、置顶、手输、复制、语言菜单、失焦与关闭。跨应用与真实引擎结果单独记录，
   未获得权限或凭据的路径不能写成已验证。
